# Titanic Survival Prediction

## Project Overview
This project is a machine learning pipeline built to predict passenger survival on the RMS Titanic. It was developed using Python, `pandas`, and `scikit-learn`. The model analyzes passenger demographics, socioeconomic status, and family structure to determine the likelihood of survival.

**Final Kaggle Submission Score: 0.77511**

## The Dataset
This project uses the famous Titanic dataset, divided into a training set (`train.csv`) and a testing set (`test.csv`). 

The predictive model relies on the following key features:
*   **Pclass:** Ticket class (1st, 2nd, or 3rd) representing socioeconomic status.
*   **Sex:** Gender of the passenger.
*   **SibSp:** Number of siblings or spouses aboard the ship.
*   **Parch:** Number of parents or children aboard the ship.

## Model Architecture
The predictions are generated using a **Random Forest Classifier**. 
*   Categorical variables (like `Sex`) are converted into numerical binary arrays using One-Hot Encoding (`pd.get_dummies`).
*   The model is configured with `n_estimators=100` and `max_depth=5` to prevent overfitting while capturing essential patterns in the data.

## Files in this Repository
*   `code.py`: The main Python script that loads the data, trains the model, and generates predictions.
*   `train.csv`: The training data containing passenger details and survival outcomes.
*   `test.csv`: The testing data used to evaluate the model.
*   `submission.csv`: The final output file generated by the script, formatted for submission.

## How to Run the Code

1. **Install Dependencies:**
   Ensure you have Python installed along with `pandas` and `scikit-learn`.
   ```bash
   pip install pandas scikit-learn
   ```

2. **Execute the Script:**
   Run the Python file from your terminal. Ensure the CSV datasets are in the same directory as the script.
   ```bash
   python code.py
   ```

3. **Output:**
   The script will train the Random Forest model and generate a file named `submission.csv` containing the predicted survival status (0 or 1) for each `PassengerId` in the test set.
